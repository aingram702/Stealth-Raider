## Detailed description
> Max 16,000 chars. Plain text.

Fly your whole browser in stealth.

The Cockpit Theme dresses Chrome in the Stealth Raider livery: a matte-black
stealth hull across the window frame, tabs, toolbar and omnibox, phosphor-teal
HUD accents, and a cockpit new-tab page with a radar-lit flying-wing crest.

Understated on the outside, unmistakable up close — built for anyone who wants a
dark, focused, mission-control browsing surface.

WHAT YOU GET
• Hull-black frame, tabs, toolbar and omnibox
• Phosphor-teal accents on the active tab and toolbar icons
• A cockpit new-tab background: HUD grid, radar rings, corner brackets, and the
  B-21 flying-wing crest
• Tuned for both normal and incognito windows

Pairs perfectly with the Stealth Raider privacy extension, but works great on its
own. Zero permissions — a theme only changes how Chrome looks.

TO REMOVE
Chrome settings → Appearance → Reset to default.

## Data usage disclosures
Data collected: NONE. A theme requests no permissions and runs no code — it only
provides colors and a background image.
